# AGA User Manual

User manual documentation for the AGA hair clinic platform.

This repository contains non-technical guides written for end users — clinic staff and patients. It covers every screen, button, form validation, and the connection between the two apps.

## Languages

- [English](en/README.md)
- [日本語](ja/README.md)

## Structure

```
en/              English documentation
├── web/         Web app (clinic staff)
└── mobile/      Mobile app (patients)

ja/              Japanese documentation
├── web/         Webアプリ（クリニックスタッフ向け）
└── mobile/      モバイルアプリ（患者向け）
```

## About the Platform

The AGA platform consists of two interconnected apps:

- **Web App** — used by clinic staff (concierges, counselors, doctors, managers, admins)
- **Mobile App** — used by patients (iOS & Android)

See [en/README.md](en/README.md) or [ja/README.md](ja/README.md) for a full description of how the two apps connect.
