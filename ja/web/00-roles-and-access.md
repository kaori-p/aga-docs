# ロールとアクセス権限

> **使用者**: すべてのクリニックスタッフ

## 概要

AGAのWebアプリでは、すべてのスタッフアカウントに**ロール（役割）**が割り当てられています。ロールによって、アクセスできるページや実行できる操作が決まります。権限のないボタンやメニュー項目は表示されません。

---

## スタッフロール一覧

| ロール | 説明 |
|--------|------|
| **Admin（管理者）** | システム全体の設定を含むすべての機能へのフルアクセス |
| **ClinicManager（クリニックマネージャー）** | 担当クリニックの運営・スタッフ・設定を管理 |
| **Chief（チーフ）** | 患者情報とスケジュール機能への広範なアクセス権を持つ上級スタッフ |
| **Doctor（医師）** | 患者カルテとカウンセリングへのアクセス権を持つ医療専門職 |
| **Counselor（カウンセラー）** | 患者カルテと予約へのアクセス権を持つ育毛カウンセラー |
| **MedicalTeam（医療チーム）** | 看護・臨床サポートスタッフ |
| **Concierge（コンシェルジュ）** | 日常的なスケジュール管理と患者対応を担う受付スタッフ |
| **Viewer（閲覧者）** | スケジュールと患者情報の閲覧のみ可能な読み取り専用ロール |

---

## 権限のないページにアクセスしようとした場合

権限のないページに移動しようとすると、アクセス可能なページに自動的にリダイレクトされます。利用できないボタンやメニュー項目は、そのロールのユーザーには表示されません。

---

## ロールの変更

ロールの変更は**Admin（管理者）**のみが行えます。アクセス権限の変更が必要な場合は、クリニック管理者にご連絡ください。
