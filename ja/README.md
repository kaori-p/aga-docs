# AGAユーザーマニュアル — 概要

AGAプラットフォームのユーザーマニュアルへようこそ。このガイドでは、AGA美容・育毛クリニック管理システムの使い方を説明します。

---

## AGAとは

AGAは、連携して動く**2つの独立したアプリ**で構成されたクリニックプラットフォームです。

| アプリ | 使用者 | 用途 |
|--------|--------|------|
| **Webアプリ** | クリニックスタッフ（受付、カウンセラー、医師、マネージャー、管理者） | 患者・予約・スケジュール・配送・クリニック業務の管理 |
| **モバイルアプリ** | 患者 | 予約の確認・ビデオ通話・薬の注文・支払い |

スタッフはWebブラウザからすべての業務を行います。患者はスマートフォンのモバイルアプリを使用します。

---

## 2つのアプリのつながり

一方のアプリで行った操作が、もう一方のユーザーに影響することがあります。以下はその対応関係です。

| Webアプリでスタッフが操作すると… | …患者のモバイルアプリに反映される内容 |
|----------------------------------|--------------------------------------|
| カレンダーで予約枠を作成する | 患者がその時間帯を予約できるようになる |
| 予約を「開始済み」にする | 患者の画面に「ビデオ通話に参加」ボタンが表示される |
| スタッフを「モバイル予約不可」に設定する | 患者がそのスタッフを予約できなくなる |
| 薬の注文を発送する | 患者の注文ステータスが「発送済み」に更新される |
| 患者に薬のサブスクリプションを設定する | 定期注文が自動的に患者の注文タブに表示される |
| サブスクリプションを一時停止・解約する | 以降の注文が生成されなくなる |
| 管理画面からプッシュ通知を送信する | 患者のスマートフォンに通知が届く |
| クーポンコードを作成する | 患者が登録時にそのコードを使用できるようになる |
| 医師が薬を処方する | 患者が注文可能な薬として表示される |

| モバイルアプリで患者が操作すると… | …Webアプリのスタッフ画面に反映される内容 |
|----------------------------------|----------------------------------------|
| 登録申請（問診票の提出）をする | スタッフの「患者登録」キューに表示される |
| 問診票を記入する | スタッフが患者のカルテで回答を確認できる |
| 予約を取る | スタッフのカレンダーに予約が表示される |
| 支払いを完了する | 注文の支払いステータスがスタッフ側に反映される |

## 用語集

| 用語 | 意味 |
|------|------|
| 予約（Appointment） | クリニックスタッフとのカウンセリングセッション |
| サブスクリプション | スタッフが設定する定期薬配送プラン |
| 注文（Order） | 薬の配送リクエスト（1回注文または定期注文） |
| 問診票 | カウンセリング前に患者が記入する健康アンケート |
| 受付カード | クリニックの場所と予約詳細を表示するカード |
