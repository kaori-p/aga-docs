# Room Schedules

> **Who uses this**: Concierge, Counselor, Doctor, MedicalTeam, Chief, ClinicManager, Admin (view); Concierge, Chief, ClinicManager, Admin (edit)

## Overview

The Room Schedules screen shows which treatment rooms are in use and when. Staff can view room availability, create room events, and manage ongoing room activities. The screen updates in real time so all staff always see the current state.

---

## How to Access

Click **Room Schedules** in the top navigation bar.

---

## View Modes

Switch between two ways to look at room availability:

| Mode | What it shows |
|------|---------------|
| **Grid View** | A 2-day overview of all rooms with their current and upcoming events |
| **Calendar View** | A 14-day overview, useful for planning further ahead |

Use the toggle buttons at the top of the screen to switch between modes.

---

## Navigating Dates

- Use the **left arrow** and **right arrow** buttons to move to earlier or later dates
- Use the **date picker** to jump to a specific date

---

## Room Groups

Rooms are organized into groups labeled **A, B, C, D, E, S,** and **N**. Each group is displayed as a section in the timeline. You can scroll to see all groups.

---

## Real-Time Updates

The screen automatically updates when:
- A new room event is created, changed, or deleted by any staff member
- A room's occupancy status changes

You do not need to refresh the page. A **connection status indicator** at the top shows whether the live update connection is active. If the connection is lost, the indicator will change — refresh the page to reconnect.

---

## Creating a Room Event

A room event marks a room as in use during a specific time period.

1. Click the **Create Room Event** button
2. A dialog opens. Fill in:
   - **Event Name** (required): What the room is being used for
   - **Room** (required): Which room to assign
   - **Event Type** (required): Select the type of activity
   - **Start Time** (required)
   - **End Time** (required)
3. Click **Save**

The event appears on the room timeline immediately.

---

## Editing a Room Event

1. Click on an existing room event on the timeline
2. A dialog opens with the current details
3. Make any changes
4. Click **Save**

---

## Deleting a Room Event

1. Click on the room event you want to remove
2. In the dialog, click **Delete**
3. Confirm the deletion

The event is removed from the timeline immediately.

---

## Viewing Ongoing Room Activity

Rooms currently in use are highlighted on the timeline. Click on an active room event to see:
- What activity is happening
- Who is assigned to the room
- When the event ends

---

## Tips & Notes

- Room events are visible to all staff — if a room is blocked, all staff members can see it
- Creating room events here does not automatically create patient appointments; they are independent
- If two staff members try to book the same room at the same time, the system will show an error to prevent double-booking
