# Login

> **Who uses this**: Patients

## Overview

The Login screen is the first screen you see after the app loads. You sign in using your phone number — no password is needed. Instead, the app sends a one-time verification code to your phone by SMS.

---

## How to Log In

### Step 1 — Enter Your Phone Number

1. Open the AGA app
2. On the Login screen, type your **phone number** in the number field
3. Check the box to agree to the **Terms of Service**
4. Check the box to agree to the **Privacy Policy**
5. Tap **Send Code**

> **Note**: You must check both agreement boxes before the **Send Code** button becomes active. If the button appears grayed out, make sure both boxes are checked.

### Step 2 — Enter the Verification Code

1. Check your SMS messages — you will receive a **6-digit code** from AGA
2. Type the code into the verification code field on the screen
3. Tap **Log In**

If the code is correct, you are taken to the main Appointments screen.

---

## Login Form Validation Rules

| Field | Required? | Rules |
|-------|-----------|-------|
| Phone Number | Yes | Numbers only (no dashes or spaces); must be a valid Japanese mobile number (10 digits) |
| Terms of Service | Yes | Must be checked before submitting |
| Privacy Policy | Yes | Must be checked before submitting |
| Verification Code | Yes | Must be exactly 6 digits; numbers only |

---

## Reading the Terms of Service and Privacy Policy

- Tap the **Terms of Service** link (blue underlined text) to read the full terms in a browser
- Tap the **Privacy Policy** link to read the privacy policy

After reading, return to the app and check the box to agree.

---

## What If I Don't Receive the Code?

- Check that the phone number you entered is correct
- Make sure your phone has a signal and can receive SMS messages
- Wait up to 60 seconds — SMS delivery can sometimes be delayed
- Tap **Send Code** again to request a new code
- If the problem persists, contact your clinic

---

## Error Messages

| Message | What it means | What to do |
|---------|---------------|------------|
| "Please enter a valid phone number" | The phone number is blank or contains non-numeric characters | Enter a 10-digit number using numbers only |
| "Invalid code" | The 6-digit code you entered is incorrect or expired | Double-check the SMS and re-enter the code. Request a new code if needed |
| "Please agree to the terms and conditions" | The agreement checkboxes are not checked | Check both boxes before tapping Send Code |

---

## Logging Out

To log out of the app, go to the **Profile** tab and tap the **Logout** button. See [Profile](08-profile.md) for details.
